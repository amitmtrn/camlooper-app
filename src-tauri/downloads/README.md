# Downloads Folder

This folder contains automatically downloaded dependencies for the Windows virtual camera implementation:

## Contents

- `softcam.dll` - The softcam DirectShow virtual camera library (downloaded automatically)
- `softcam.dll` (32-bit) - 32-bit version for compatibility with 32-bit applications
- `softcam.dll` (64-bit) - 64-bit version for compatibility with 64-bit applications

## Automatic Download

The softcam DLL files are automatically downloaded from the official GitHub repository (https://github.com/tshino/softcam) during the first application run on Windows.

## Manual Setup

If automatic download fails, you can manually download the softcam DLL files from:
https://github.com/tshino/softcam/releases

Place the DLL files in this folder and they will be automatically detected and used by the application.
